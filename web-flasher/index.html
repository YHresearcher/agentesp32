Chưa chọn file
02

Flash ESP32-S3

Kết nối board qua cổng COM (USB-to-UART) hoặc USB tương thích, dùng Chrome/Edge trên máy tính. Ngắt Serial Monitor trước khi flash.

Trình duyệt này chưa hỗ trợ Web Serial. Dùng Chrome hoặc Edge trên desktop. Cần HTTPS hoặc localhost để sử dụng Web Serial.

Bản đầu tiên cần bạn chọn file .bin. Không hỗ trợ tự tải firmware nếu chưa có bản build thành công.

03

Serial Monitor & Boot Log

Chưa kết nối
[ModESP32] Sẵn sàng nhận log qua USB.\n

Serial Monitor và công cụ flash dùng cùng cổng USB: hãy đóng một bên trước khi sử dụng bên kia. Để đọc boot log, kết nối serial rồi nhấn RESET/EN trên board.

04

Gửi log lỗi để chẩn đoán

Log chỉ nằm trên máy bạn cho đến khi bạn tự tải/copy hoặc gửi. Chọn Chuẩn bị GitHub Issue để mở bản nháp với một đoạn log đã được che dữ liệu nhạy cảm. Hãy đọc lại nội dung trước khi đăng công khai.

Chưa gửi dữ liệu nào.
